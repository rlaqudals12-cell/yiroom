# /skill-audit 명령어

**목표**: 내가 Claude Code를 실제로 어떻게 쓰는지 연구한 다음, 반복 작업을 싼 모델도 안정적으로 돌릴 수 있는 깔끔하고 재사용 가능한 시스템으로 만든다.

**역할**: 너는 내 AI 시스템 분석가다. 순서대로 진행한다.

## 대상

$ARGUMENTS (미지정 시 `.claude/` 전체 + `memory/` + 최근 세션)

## 1. 연구

다음을 전부 살펴 내가 제일 많이 쓰는 용도와 손으로 반복하는 작업을 찾아낸다:

- 최근 커밋(`git log --oneline -30`), 세션 기록(`.claude/sessions/`, `docs/sessions/`)
- `CLAUDE.md` + `apps/*/CLAUDE.md`, 저장된 프롬프트/메모리(`memory/`)
- 스킬/커맨드 폴더(`.claude/commands/`, `.claude/skills/`), 규칙(`.claude/rules/`), 에이전트(`.claude/agents/`)

## 2. 스킬 점검

기존 커맨드·규칙·에이전트를 하나씩 다 훑는다. 중복되거나, 낡았거나, 겹치거나, 망가진 걸 표시한다. 각각에 대해:

- **유지 / 수정 / 병합 / 삭제** 중 하나를 **한 줄 이유**와 함께 정한다

## 3. 개선 및 생성

- 가장 자주 반복하는 워크플로우를 **명확한 트리거·입력·단계·출력**을 가진 재사용 스킬로 다시 쓴다
- 빈 곳을 찾아서 제일 강력한 **두 개를 새로** 만든다

## 4. 기준 정리

싼 모델(Sonnet 등)이 기준 모델(Opus 4.8)에 가까운 품질을 내도록, **CLAUDE.md에 그대로 넣을 수 있는 시스템 지시 블록**을 써준다.

## 5. 보고

뭘 점검했고, 뭘 고쳤고, 뭘 새로 만들었고, 어디에 저장했는지 정리한다.

## 출력 형식

```markdown
## 스킬 점검 결과

### 사용 패턴 (연구 결과)

- 가장 많이 쓰는 용도 / 손으로 반복하는 작업

### 점검 판정 (유지/수정/병합/삭제 + 이유)

| 항목 | 판정 | 이유 |
| ---- | ---- | ---- |

### 신규/개선 스킬

- [이름] : [트리거 → 입력 → 단계 → 출력]

### CLAUDE.md 삽입용 시스템 지시 블록

[복사-붙여넣기 가능한 블록]
```

## 하드 룰

- **삭제하기 전엔 반드시 사용자에게 먼저 물어본다.** (병합·수정도 파괴적이면 확인)
- `.claude/rules/` 정리 시 `paths:` 경로 스코프를 활용해 always-on 지침을 줄인다(주의력 희석 방지).
