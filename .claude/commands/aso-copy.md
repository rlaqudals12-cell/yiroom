# /aso-copy 명령어

Google Play 리스팅·ASO 카피(앱 이름, 짧은/전체 설명, 업데이트 노트, 스크린샷 문구)를 작성합니다.
Play 정책 위반으로 심사 반려되는 표현을 사전에 차단하는 것이 이 스킬의 핵심입니다.

## 필드 제한 (초과 시 생성 실패로 간주)

| 필드          | 제한       | 비고                                  |
| ------------- | ---------- | ------------------------------------- |
| 앱 이름       | 30자       | 이모지·"무료"·"최고"·순위 문구 금지   |
| 짧은 설명     | 80자       | 핵심 키워드 1-2개 자연 포함           |
| 전체 설명     | 4,000자    | 키워드 스터핑 금지 (반복 5회 이상 ❌) |
| 업데이트 노트 | 500자      | 사용자 언어로, 내부 용어 금지         |
| 스크린샷 문구 | 화면당 1줄 | verdict-first, 기능명 나열 금지       |

- 글자 수는 **언어별로 각각 검증** (ko/ja/zh는 같은 30자라도 정보량이 다름 — 번역 후 재확인).

## 브랜드 고정값 (변경 금지)

- **정체성**: 이룸 = "나를 다 아는 전속 뷰티팀" (개인 스타일리스트 + 외모 컨설턴트 + 피부 관리사)
- **슬로건**: "온전한 나를 찾는 여정"
- **포지셔닝**: 전문가 90% 수준을 무료·즉시·24/7. 진짜 경쟁자는 "아무것도 안 하는 것".
- **타깃**: 여성 우선 (남성 배제 표현 금지)
- **핵심 무료 강조 OK** — 단 "무료" 단어는 앱 이름 제외, 설명에서만.
- 도메인 표기: yiroom.app (워터마크·링크 통일)

## 정책 가드 (심사 반려 방지)

1. **비의료 고지**: 피부/체형 분석은 미용·참고 목적. "진단", "치료", "의학적" 표현 금지 → "분석", "제안", "참고" 사용.
2. **생체 데이터**: 얼굴/신체 사진 언급 시 반드시 "동의 후 분석·프라이버시 정책 링크" 맥락 유지 (BIPA 동의 게이트는 앱에 구현됨 — 리스팅 문구가 이를 부정하면 안 됨).
3. **성과 보장 금지**: "예뻐집니다", "무조건 어울립니다" ❌ → "나에게 맞는 기준을 찾아드려요" ✅
4. **경쟁사 비방·상표 언급 금지** (키워드에 타 앱 이름 삽입 ❌).
5. **AI 표기**: AI 분석임을 숨기지 않되, "AI가 다 해준다"식 과장 금지 — 신뢰도·재현성 서사 우선.

## 키워드 전략 (4언어)

| 언어 | 1순위 키워드                                        | 보조                       |
| ---- | --------------------------------------------------- | -------------------------- |
| ko   | 퍼스널컬러, AI 피부 분석, 체형 분석                 | 뷰티 컨설팅, 코디, 톤 진단 |
| en   | personal color analysis, AI skin analysis, K-beauty | color season, style match  |
| ja   | パーソナルカラー, 肌診断, 骨格診断                  | K-beauty, メイク提案       |
| zh   | 个人色彩, AI皮肤分析, 韩系美妆                      | 穿搭建议, 色彩季型         |

- 짧은 설명에 1순위 키워드 1개 이상 자연스럽게. 전체 설명 첫 3줄(접기 전 노출 영역)에 핵심 가치 + 키워드 배치.

## 작성 규칙

- **verdict-first**: 첫 문장 = 사용자가 얻는 것. 기능 나열은 뒤로.
- 구조(전체 설명): ① 한 줄 가치 제안 → ② 5축 분석이 해주는 것(퍼스널컬러·피부·체형·헤어·메이크업) → ③ 매일 브리핑/결정의 순간(스캔) 시나리오 → ④ 무료·프라이버시 신뢰 → ⑤ CTA.
- 한국어는 해요체, 자연스럽고 정중하게. 번역은 직역이 아니라 시장별 어법(ja: 骨格診断 문화, en: color season 어휘).

## 출력 형식

언어별 섹션으로, 각 필드에 글자 수 카운트 병기:

```markdown
## ko-KR

- 앱 이름 (23/30): ...
- 짧은 설명 (76/80): ...
- 전체 설명 (2,840/4,000): ...
```
