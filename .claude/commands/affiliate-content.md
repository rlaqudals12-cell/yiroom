# /affiliate-content 명령어

제품 추천 문구·링크 삽입·고지가 포함된 어필리에이트 콘텐츠를 작성합니다.
**핵심 가치는 카피가 아니라 가드레일 강제** — 아래 규칙을 위반하는 콘텐츠는 생성하지 않습니다.

## 하드 가드레일 (위반 시 생성 중단)

### 1. 인증 리테일러만 링크 (가짜 방지 = 마케팅 무기)

| 리테일러        | 프로그램           | 수수료 | 상태                                        |
| --------------- | ------------------ | ------ | ------------------------------------------- |
| 쿠팡            | 파트너스 AF1075777 | ~3%    | ✅ 가입 완료 (자동 전환은 실적 15만원 후)   |
| YesStyle        | Awin (미국 앵커)   | 10%    | ⏳ Awin 가입 대기 (도메인 yiroom.app 필요)  |
| Stylevana       | Awin               | ~8%    | ⏳ YesStyle과 동시 신청                     |
| 올리브영 글로벌 | 자체 프로그램      | 13%    | ⏳ 가입 대기 (⚠️ 미국 배송 불가 — 비미국용) |
| iHerb           | 자체 프로그램      | ~5%    | ⏳ 승인 쉬움                                |

- 위 목록 밖 리테일러 링크 금지. 미가입 프로그램의 딥링크 선반영 금지.
- ⚠️ **`deeplink.ts`의 iHerb·무신사 파라미터는 가짜(수수료 0)** — 실제 발급 파라미터로 교체 전까지 해당 링크 사용 금지.
- 지역 라우팅: 미국 사용자 → YesStyle 앵커. 비미국 → 올리브영 글로벌 우선 (미국 배송 X 주의).

### 2. 어필리에이트 고지 필수 (모든 콘텐츠·모든 언어)

콘텐츠 상단 또는 링크 인접 위치에 반드시 포함:

- **한국어**: "이룸은 위 링크를 통한 구매 발생 시 판매자로부터 수수료를 받을 수 있습니다. 추천은 수수료와 무관하게 분석 결과 기준으로 선정됩니다."
- **영어(FTC)**: "Yiroom may earn a commission from purchases made through these links, at no extra cost to you. Recommendations are based solely on your analysis results."
- 인앱 표면은 기존 어필 고지 컴포넌트(7월 배포됨)를 재사용 — 새 고지 UI 중복 생성 금지.

### 3. 추천 중립성 (순위 비매각 원칙)

- 추천 순위 = **best-fit 순서만** (사용자 퍼스널컬러·피부·체형 분석 결과 기준). 수수료율이 순위에 영향 주는 문구·구조 금지.
- 글로벌 브랜드 포함 중립 추천 — K뷰티만 강제하지 않음. 단 **스킨케어 = 한국 리드** 서사는 허용(사실 기반).
- 노출·클릭 과금형 표현("광고", "스폰서 제품") 금지 — 이룸은 결과(구매) 과금만.

### 4. 색조 = 톤가드 필수

- 색조(립·블러셔·아이섀도) 추천 문구는 반드시 퍼스널컬러 톤 조건을 명시: "쿨 서머이신 분께", "웜 스프링 팔레트 기준" 등.
- 톤 미상 사용자 대상 색조 일괄 추천 금지 → "분석 먼저" CTA로 유도.
- 스킨케어는 톤 무관이므로 톤 조건 불필요 (피부타입 조건은 권장).

### 5. 법적 표현 제한

- 의료 효능 주장 금지: "치료", "개선 보장", "피부과 수준" ❌ → "~에 도움을 줄 수 있는", "분석 결과 기준" ✅
- 최상급 표현("최고", "1위") 근거 없이 금지 (표시광고법).
- 가격·할인율은 변동 가능 고지 없이 확정 표현 금지.

## 콘텐츠 작성 규칙

- **verdict-first**: 결론(이 제품이 맞는 이유) 먼저, 근거는 뒤에 접기.
- **타깃**: 여성 우선 (남성도 사용 가능한 표현 유지). 자연스럽고 정중한 한국어(해요체).
- **연결 서사**: 단품 추천이 아니라 "당신의 분석 결과 → 이 제품" 인과 연결 1문장 필수.
- 언어: 기본 한국어. 글로벌 표면은 4언어(ko/en/ja/zh) — 고지 문구도 해당 언어로.

## 출력 형식

```markdown
## [제품명] — [한 줄 verdict]

[분석 결과 연결 1문장: "쿨 서머의 저채도 팔레트에 맞는 ~"]

- 왜 맞는가: [근거 1-2개, 접기 가능]
- 구매: [인증 리테일러 딥링크] (지역: US=YesStyle / 기타=올영글로벌)

[고지 문구 — 해당 언어]
```

## 사용 예시

```
/affiliate-content 쿨서머 립 추천 3종 (미국 사용자)
/affiliate-content 건성 스킨케어 루틴 콘텐츠 (올영글로벌)
/affiliate-content 공유카드 하단 제품 CTA 문구
```
