## 0. 궁극의 정의 — 관찰 가능한 한 문장

> **"옷·화장품·헤어 결정의 순간에, 사람에게 묻기 전에 이룸을 먼저 연다."**

"진짜 전속 팀과 구별할 수 없는 관계"는 측정 불가·도달 불가라 궁극이 될 수 없다(패널 판정).
궁극은 위 문장 하나다 — 매대 앞에서, 옷가게에서, 미용실에서 관찰할 수 있다.
5축 분석은 수단이며, 이 문서의 모든 100% 정의는 이 문장의 형식(누가·어디서·무엇을 하는가)을 따른다.

### 0.5 물리적 한계 — 이룸이 영원히 못 하는 것

촉감(원단·제형을 만지기) · 실물 전달 · 예약 대행 · 현장 시술. 궁극의 범위는 **조언
레이어에서의 대체**로 한정한다. 이 한계 밖의 항목은 어떤 로드맵에도 넣지 않는다.

### 0.7 고객이 누구인가

여성 우선, 남성 사용 가능(배제 표현 금지 — ADR-121 결정 3·4). 성별 분기가 필요한 축은
체형(C)·헤어(H)와 추천 레이어뿐이고, 판정 엔진에는 성별을 주입하지 않는다(ADR-121 결정 2).

### 0.9 모든 단계 공통 가드 (이 가드를 통과한 100%만 유효)

- **감정 4금지**: 불안·열등감·강박·비교를 만드는 설계 금지 (yiroom-philosophy §7 존속).
- **안 열어도 손해가 없어야 한다**: 스트릭·연속 기록·놓친 브리핑 압박·부재 푸시 금지.
  브리핑은 열었을 때만 가치가 있고, 밀린 브리핑은 쌓이지 않는다.
- **측정 등급 없는 %는 쓰지 않는다**: 모든 달성도에 [측정됨/추정/미측정] 태그 의무.
- **원가 태그 없는 100% 정의는 채택하지 않는다** (§4 원가 계약 참조).

## 2. 관계 4단계 + 기반층 — 각각의 100%와 현재

> 구조 판정(패널): 시착은 3단계의 하위 수단, 고객 노트는 단계가 아니라 기반층(이중 계산 금지),
> 캡슐은 관계가 아니라 관계를 실어 나르는 소재. 달성도는 가중평균이 아니라 **신호등**
> (⬜ 미착수 · 🟨 부분동작 · 🟩 실사용자에게 동작)으로, **웹/모바일 2열·대표값은 모바일**(출시 vehicle).

### 1단계. 첫 미팅 — "10분 안에, 나를 아는 팀이 생겼다" [원가: 판정 1회 ₩7~30]

100% =
① **판정 라벨 재현율 ≥95%**(퍼컬 주 시즌 기준, 12톤 세부는 별도 수치 분리).
선행 조건: 판정 호출 temperature 0 + 모델 버전 핀 + 이미지 지문 결과 캐시(같은 사진→저장된
판정 반환). 공개는 실측 후에만 — n·프로토콜·측정일·모델 버전 병기 + "모델을 바꿀 때마다
재측정해 갱신합니다" 약속형. ⚠️ 현행 prod의 "검증했어요" 과거형 문구(4로케일)는 실측 전까지
회수 대상.
② **불일치의 정직한 공시** — "전문가 3인도 서로 60~75%만 일치하는 영역입니다. 이룸은 같은
사진에 항상 같은 답을 주고, 근거를 공개합니다." ("전문가 대비 90%"는 정답 라벨이 존재하지
않아 정의 불성립 — 폐기. 대조가 필요하면 바터 파일럿 + 4자 일치 분포 공시로만.)
③ 화면의 모든 "근거"는 실제 관찰값(날조 0), 폴백은 전면 고지.
현재: 웹 🟨 / 모바일 🟨 [추정] — 판정 엔진·정직성 인프라 상위, 재현성 [미측정]·근거 수리 중(배치 N).

### 2단계. 매일 브리핑 — "매일 아침 열 이유가 있는 한 문장" [원가: ₩0 결정론 조립]

100% = 내 옷장(오늘의 코디)·내 제품 후속·내 피부 추이·날씨·어제 내 응답이 반영된 조립 브리핑.
열면 3초 안에 오늘의 결정이 끝난다. 단 0.9 가드 — 안 열어도 손해 없음.
현재: 웹 🟨 / 모바일 🟨 [측정됨: 코드 실측] — 화법·정직성 가드 완결, 소재가 팔레트+피부 추이
수준(옷장 미연결 — P-1, 모바일은 폐루프 응답 미렌더 = Tier A 패리티 항목).

### 3단계. 결정의 순간 — "매대 앞/옷가게/미용실에서 꺼낸다" [원가: 판정 1회 ₩7~27]

100% = 스캔 2초 → "사도 됨/말 것 + 이유 + 내 팔레트와의 거리". 옷 사진 → 체형·팔레트 적합도.
컷 사진 → 어울림 판정. **시착은 이 단계의 하위 수단**: 드레이핑은 보여주기가 아니라 판정
(광학 엔진 — 원가 ₩0)까지가 100%. 실물 착장(FASHN)은 궁극이 아니라 조건부 실험 —
게이트 3종 동시 충족 시에만: (i) 어필 링크 상품 상세에서만 (ii) 유저당 주 1회 전용 캡
(iii) 직전 30일 CPA 매출 > FASHN 청구액 ×3. 시착 표현은 "현재 상태의 시각화" 한정 —
효과·개선·기간 암시와 before/after 슬라이더 금지, 생성 이미지는 본인 한정·공유는 명시 옵트인.
현재: 웹 🟨 / 모바일 🟨 [추정] — 스캔·코디·컷 존재, 파우치 실판정 무동작(한글 매칭 — P-1),
드레이핑 판정 미배선(P-1), 속도·오프라인 미달.

### 4단계. 실천 — "아는 것"이 "입고 바르는 것"이 된다 [원가: ₩0 규칙 조립 + gap-apply 1회]

100% = 캡슐 원 설계(어떤 상황에서도 대안이 있는 시스템)가 **실옷장·실제품 위에서** 동작:
코어 N피스 제안(숙련도 함수·패션 33 상한)·시즌 로테이션·상황 5종(선택과부하·결정피로·
비호환·고착·과잉) 해소. placeholder 엔진이 아니라 closetMatcher 계통과의 결합이 본체.
현재: 웹 ⬜~🟨 / 모바일 ⬜ [측정됨: curate() 전부 placeholder, 실옷장 미접속] — 데이터층은
gap-apply로 부활 직전.

### 기반층. 고객 노트 — "떠나도 남는 것을 주되, 남을 이유를 매일 새로 만든다"

단계가 아니라 1~4단계 전부의 **승수**다(노트 없이는 2~4단계가 상한에 막힌다).
100% = 응답·착용·구매·경과가 시계열 노트로 쌓여 **다음 제안의 후보군과 순서가 그 기록으로
바뀐다**(인과 귀속 "+12" 문구는 §1 버림 표의 법무 항목 — 상관·기록 재생까지만).
불변식: **노트는 언제든 전량 내보내기·삭제 가능 — 해자는 잠금이 아니라 깊이다.**
선행 순서 고정: 촬영조건 정규화 → 재현성 확보(1단계①) → 시계열 저장 → 사용기간 기록.
현재: ⬜ [측정됨: 전용 스키마 0건, rating 1종 재사용] — 가장 비어 있고, 원가 ₩0이며,
유일하게 복제 불가능한 층.

## 3. 지표 — 졸업과 동행의 화해 (쌍 North Star)

판단력은 졸업시키고, 관계는 유지한다. 어느 한쪽만 오르면 실패다:

- **North Star A (이룸의 능력)**: 노트 반영 제안 vs 미반영 제안의 A/B — 반영 팔의 부정 응답
  비율이 유의하게 낮은가. (수락률 절대값은 반지표 — yiroom-philosophy §11 존속.)
  선행: analytics_events에 recommendation_id·source(note|generic)·accepted 3필드 규약.
- **North Star B (사용자의 능력)**: 내재화 연결 수 — ConnectionStatus의
  internalized+independent 계수(계측기 lib/connection-awareness/ 실재, 배선만 남음).
- **Aha 지표**: ~~2번째 분석 완료율~~(가입=통합분석 직행으로 사건 자체가 소멸 — 3월 정의
  폐기) → **2번째 세션 재방문 + 축 1개 추가·재분석 완료율**.
- **반지표 존속**: 세션 시간·알림 클릭률·추천 수락률 절대값.

## 4. 수익·기술 불변식 — 선언이 아니라 검증 가능한 계약

1. **추천 정렬 입력에 수수료(commission/rate)·재고 인센티브를 넣지 않는다** — 정렬 함수
   시그니처가 수수료 필드를 받지 못하게 테스트로 고정.
2. **인증 리테일러 외 딥링크 금지**, 수수료 귀속 불가 링크는 파라미터를 지어내지 않고 원본
   통과(기존 실천의 정본 승격).
3. **핵심 판정·조언·데이터는 영원히 무료.** 유료는 원가 전가형 생성 이미지 크레딧(Tier B)
   1종 한정. 무료 사용자의 판정 품질이 열등해지는 설계 금지(무료-유료 비대칭 금지).
4. **원가 계약: 유저 1인 월 AI 원가 ≤ ₩100**(어필 기대수익 유저당 월 ~₩83의 안쪽).
   초과 기능은 Tier B 게이팅 필수 — 게이팅 없는 초과 기능은 궁극 정의에 넣지 않는다.
5. 결정론 우선(판정에만 AI, 조립은 규칙) · 폴백 전면 고지 · 원본 비저장 기본(저장 옵트인).

## 6. 마일스톤 — %가 아니라 산출물 이름으로 (한 분기에 관계 단계 하나)

- **출시 게이트**: 배치 N·P·Q·O 산출물 + 재현율 수치 1건 실측(스크립트 산출물 경로 명시,
  그 전까지 "검증했어요" 문구 회수) + 브리핑 문장에 옷장 아이템 등장 + 도달축 가용성 해소
  - Play 제출.
- **다음 분기 = "고객 노트 v1"** (원가 ₩0·해자·전용 스키마 SDD 선행) → 그다음 분기 =
  캡슐×실옷장 결합 → 시착(FASHN)은 §2 3단계 게이트 충족 전까지 동결.
- "90%"류 총점은 두지 않는다 — 계기판 3지표(GROWTH-DECISION-DASHBOARD)가 전진 게이트다.

## 7. 궁극의 시효 — 기술 조건부성 (2026-09-02 창업자 통찰)

이 문서의 궁극은 고정점이 아니라 **현 기술 지형(스마트폰 카메라 + LLM 판정)에서의 최적
표현**이다. 기술이 바뀌면 궁극도 바뀐다 — 단, 바뀌는 층과 안 바뀌는 층을 구분한다.

**불변 코어 (기술이 바뀌어도 유지)**:

- 관계 4단계의 본질 — 결정의 순간에 이룸이 **첫 참조**가 되는 것 (§0의 궁극 문장)
- 정직성·영원 무료·중립·감정 가드 (§0.9·§4 불변식)
- 고객 노트 기반층 — 어떤 인터페이스든 노트가 깊을수록 조언이 정확해지는 구조

**가변 껍질 (기술 전환 시 재정의)**:

- **디바이스**: 폰 → AR 글라스/웨어러블 상용화 시 3단계 "꺼내 본다"가 "이미 보인다"로
  진화 — §1 버림의 기록에 조건부로 남긴 "실시간 영상 분석(기술 성숙 대기)"이 그때
  되살아나는 문이다.
- **판정 엔진**: LLM → 차세대 AI 전환 시 1단계 재현성 선행조건(temperature 0·모델 핀·
  이미지 해시 캐시)은 그 시대 기술로 재구성한다. 재현성이라는 **약속**은 불변, 구현은 가변.
- **원가 계약**: §4의 ₩100은 절대값이 아니라 "어필 기대수익 안쪽"이라는 **비율 원칙** —
  수익 구조·추론 원가가 바뀌면 재산정한다.
- **물리적 한계(§0.5)**: 한계 목록 자체도 개정 시 재검토 대상(예: 햅틱 성숙 시 촉감 항목).

**개정 규약**: 다음 트리거 발생 시 v4 개정에 착수한다 —
①웨어러블/AR 디바이스의 대중 상용화 ②실시간 멀티모달 판정의 원가·정확도 성숙
③판정 모델의 패러다임 전환(LLM 이후). 개정 시에도 §1 버림의 기록은 삭제하지 않고
누적한다 — 재검토는 "버림의 이유가 소멸했는가"부터 시작한다.
