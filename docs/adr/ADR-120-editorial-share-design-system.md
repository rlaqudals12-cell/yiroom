# ADR-120: 에디토리얼 공유·랜딩 디자인 시스템 (무점수 진단지 + 크림 고정 지면)

- **상태**: accepted
- **날짜**: 2026-07-18 (구현 7/15~18, 소급 문서화)
- **관련**: ADR-113(비주얼 표현) · ADR-119(법적 게이트) · memory `design-taste-moat-2026-07` · `feature-economics-and-hooks-2026-07`

## 배경 (Context)

퍼컬 문화에서 결과 화면·공유카드는 통째로 캡처·공유되는 바이럴 표면이다. 기존 표면(결과 페이지 다크 네온·랜딩 다크 글래스·시즌 그라데 카드)은 AI-slop 4신호(장식 그라데·Sparkles·자간 대문자 라벨·글로우)를 밟아 "뷰티인데 IT 대시보드" 인상을 만들었다. 한편 GPT 생성 목업(AI NEWPO류 진단지)이 시각 기준선을 제시했고, 사용자 검증 결과 "틀은 목업, 데이터는 실분석"이 방향으로 확정됐다.

## 결정 (Decision)

### 1. 공유 표면 3포맷 + 얼굴 이원화

- **E+ 정체성 카드**(square/story): 블러시 크림 고정 hex 지면·진단 팔레트 전면 밴드가 주인공·헥사곤-Y 인장·발급번호(실측 순번)·초대문구. 얼굴 미포함이 디폴트.
- **드레이핑 카드**(옵트인): 내 사진 + zero-mask 캔버스 드레이프(비생성 ₩0). 명시적 옵트인(기본 OFF)·기기 내 합성·fetch 0(서버 미저장). ~~눈가림 밴드~~는 문화 검증(검은 밴드=성형·의료 검열 코드, 완전가림=기본 카드의 열화 부분집합)으로 **기각** — 얼굴無 기본 / 얼굴 그대로 옵트인의 이원화만 유지.
- **진단지 리포트**(세로 한 장, 캡처 scale 2.5): 계절 인장 → 속성표(명도/채도=12톤 정의 파생·대비=실측시만) → keyInsights 체크 → 컬러 4단(베스트+포인트+금속+피할색·취소선) → 2×2 프로파일 카드(아이콘 앵커) → 어울림 도트(저장된 suitability만) → 액션플랜 → 세리프 총평 → **분석 신뢰도 N%+재현성 배지**. 사진 옵트인 시 드레이프 적용 + 섹션 썸네일 다회 등장.

### 2. 외모 점수화 전면 금지 (타협 없음)

종합점수·별점·매력도·레이더 차트·부위별 계측 수치는 채택하지 않는다. 근거: ①해당 계측 데이터가 없음(넣으면 날조) ②얼평 백래시 실증 ③레이더=대시보드 미감(슬롭). 점수의 자리 = 속성표 + 신뢰도(진단의 점수, "정확도" 단어 금지 — 검증 불가 주장) + 재현성 + 발급번호. 유일 예외 = 피부 "컨디션 N점"(측정 가능 상태 지표, 기존 패턴).

### 3. 랜딩 = 타이포·여백 포워드 + 크림 라이트 고정

- 프리미엄 뷰티 랜딩의 두 문법(사진-포워드 vs 타이포-포워드) 중 **타이포·여백-포워드**(이솝·설화수 축)를 채택 — 사진 자산 없음이 이 축에선 약점이 아님.
- 구성: 약속 배너(영원히 무료) → 세리프 히어로+실카드 부유 → 정직 신뢰 밴드 4 → **12톤 스펙트럼 스트립**(실판정 팔레트, CSS 호버 인터랙션) → 5축 그리드 → 실카드 3종 미리보기+게이트 카피 → 미션 세리프 선언.
- **크림 라이트 고정**(테마 토글 무시): 랜딩·카드·리포트는 "지면"이라 다크 변형을 두지 않는다(프리미엄 뷰티 관습, 다크 파손 원천 해소). 앱 내부는 시맨틱 토큰 유지.
- **인물 사진 전면 배제**(스톡=초상권 리스크·생성형=소비자 70% 불편+브랜드 자기모순). 무드 층 = CSS 컬러필드+종이 그레인(SVG feTurbulence 인라인)+오버사이즈 세리프.

### 4. 이펙트 규율

채택: 포토카드 틸트(±6°, 캡처 무영향)·종이 그레인(opacity ≤0.05)·포일 마감 토글. 기각: WebGL 3D·파티클·글로우·backdrop-filter(캡처 미지원+슬롭).

### 5. 캡처 규약 (공유 산출물 공통)

고정 hex(테마 무관)·img 태그 0(캔버스/CSS만)·backdrop-filter 금지·리포트 scale 2.5(장변 4096px 안전권)·서명 URL 이미지는 crossOrigin='anonymous'.

## 근거 (Evidence)

- 페르소나 시뮬 4종(Opus): 신뢰 4:0 이룸 우세, 무점수 "다행 80%" 전원 수렴.
- 비주얼 패널 5인: 시각 완성도 4/5 이룸 > GPT목업(7.5~8 vs 7~8). mustNotTouch 합의(세리프 이탤릭 넘버링·풀블리드 스트립·뮤트 채도 규율·hex 병기·정직 문구).
- 레퍼런스 리서치 3갈래(브랜드 7곳 구조 분해·진단 퍼널 7곳·이미지 자산 전략) — memory `design-taste-moat` 참조.

## 트레이드오프 (Trade-offs)

- 목업의 "정보 밀도" 일부(부위 계측·헤어 시뮬 사진)는 포기 — 데이터 정직성이 우선. 생성 드레이핑·헤어 틴트는 Tier B 게이팅 백로그로 이관.
- 크림 고정 지면은 다크 선호 유저에게 이질적일 수 있음 — "인쇄물" 메타포로 수용(카드·진단지와 동일 원리).
- 12톤 큐레이션(베스트6+포인트3+금속2+avoid4)은 수작업 유지 비용 — 톤 표준 관습이라 변경 빈도 낮음.
